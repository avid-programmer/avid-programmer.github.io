Lately, I was learning about OpenWrt and read few tutorials and documentation on it. Now, I am going to tell you how you can install it in Virt-manager (which is a graphical frontend to manage QEMU virtual machines through libvirt).

Downloading image:#

Go to the Downloads section of OpenWrt website.

  • Select the ‘Stable Release’.
  • Now, select x86 at the bottom of the page.
  • Finally, select 64/.

Here, you will see a bunch of image files for x86-64 architecture. Let us go through each of the files:

  • efi image files : Files containing efi in their name is used for systems that use UEFI for boot process.

  • rootfs image files : Files containing rootfs in their name contain only the filesystem and OS, but no bootloader and no kernel.

  • generic-kernel.bin : This file only contains raw Linux kernel and nothing else.

  • squashfs : Files containing squashfs in their name contain read only filesystem. Typically, used for flashing physical home routers.

  • combined : Files containing combined in their name contain full disk image.

We will use generic-ext4-combined.img.gz

Now, we have to unzip this file to extract the image file.

gunzip generic-ext4-combined.img.gz

Creating isolated network:#

Open Virt-manager.

  • Select QEMU/KVM. Then, Edit –> Connection Details.

  • Select Virtual Networks.

  • Click on + symbol at the bottom.

  • Fill in the details as follows
    Name: my-lan
    Mode: Isolated
    IPv4 Configuration: Uncheck Enable IPv4
    IPv6 Configuration: Uncheck Enable IPv6

Installing OpenWrt:#

Open Virt-manager.

  • Click on “Create a new virtual machine”.

  • Select “Import existing disk image”.

  • Provide the path where you unzip the file. And in the operating system choose “Generic Linux 2024”.

  • Choose Memory and CPU.

  • Check “Customize configuration before install”. Click on “Finish”.

Customizing configuration before install:

  • Select NIC from the left side.
    • Go to Network Source and select ‘my-lan’.
  • Click on ‘Add Hardware’.
  • Now, click on ‘Network’ and then Network Source as ‘default’: NAT.
  • Click on ‘Finish’.

  • Click on ‘Begin Installation’.

Modifying OpenWrt VM:#

  • Open the OpenWrt VM.

  • Edit the file /etc/config/network using vi.

  • Modify the block starting with config interface 'lan'

    • Change list ipaddr '192.168.1.1/24' to list ipaddr '10.0.0.1/24'

    • Run /etc/init.d/network restart

Creating a network:#

  • Install Linux Mint in another VM.

  • Open the Linux Mint VM but do not start it.

  • Click on the light bulb icon.

  • Select NIC on right side and then in ‘Network source:’ select ‘my-lan’.

  • Now, first start the OpenWrt VM. Once it is successfully booted, start Linux Mint VM.

  • Now, all your traffic from Linux Mint VM, will be routed through OpenWrt VM.
