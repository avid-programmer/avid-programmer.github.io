OpenSnitch

July 24, 2026 · 2 min

As I was reading about Nftables and eBPF, I thought struck in my mind that there are firewall rules to block/control incoming connections. You can install Gufw which is a graphical frontend to ufw. By clicking a button, you can deny all unauthorized incoming connections. Yes, you can control outgoing connections too but for that you have to create manual rules and it is not as easy as it sounds. Wouldn’t it be great if I can view each outgoing connection on connection to connection basis. As I was reading about eBPF and Linux network programming, so I knew that for each connection a socket is created and if I am able to hook into kernel functions responsible for socket creation I would be able to intercept and see every outbound connection.

While I was researching on this idea, I found out about OpenSnitch so, I decided to drop the idea of creating my own bpftrace script to view every outbound connection right now and first try OpenSnitch and then when I am comfortable with it, I will create my own script. This way I would be able to know what is possible and what is not possible. So, I started using OpenSnitch.

When I launched Firefox, I got this pop up screen which said that Firefox is trying to connect to detectportal.firefox.com When I searched it on the internet, I found that it is a website used by Firefox to detect whether a public network requires a login page to connect to the network. When I was doing my internship in a startup, I used to connect to the network and launch Firefox, it would automatically get me to the login web page. At that time, I did not pay any attention to it. But now, it became clear how this thing worked and I quickly realized that there is no magic in computer science.
